## 布局（像素）

```
y   0.. 39  顶栏 40        ● 在线        客厅 · 14:32        ((•)) 5G
y  40..259  主区 220
            左 2/3 (x16..304)                     右 1/3 (x320..464)
              房间名     32px  y52                  像素机器人 96×96
              状态+强调  20px  y108（橙条 4×22）     天线/方头/方眼/三段嘴
              分段条     248×12 y146  12 段          纯几何绘制，不用图片
              3 行明细   14px  y184/208/232
y 260..319  底栏 60        字幕条 464×52 r10 墨底纸白字
```

- **左 2/3 = 288 px**（16..304），**右 1/3 = 144 px**（320..464），中间 318 处一条 1 px 分隔线。
- 顶栏与主区之间 1 px 墨线；明细行之间有浅色（#D8D5C6）1 px 分隔。
- 分段条 12 段、段宽 18 px（`(248-11×3)/12≈17.9`，末段取整）、间距 3 px；右侧数字 `09 / 12` 用等宽 14px。
- 明细三行行距固定 **24 px**（y184/208/232）；若某行回落 20px，行盒 26 px 会与相邻行重叠 2 px，但重叠落在上下行留白里，**不压字、不裁切**（不改成 26 px 行距）。

## 配色

| 角色 | 色值 | 用法 |
|---|---|---|
| 纸白（底） | `#F4F3EA` | 全屏背景、机器人面部填充 |
| 墨黑（主） | `#202B2D` | 文字、线框、分段条已填充段、字幕条底 |
| 暖橙（强调） | `#E2703A` | **每屏只用一处**：状态文字左侧 4×22 竖条 |
| 次要灰 | `#6B7372` | 明细标签 |
| 分隔线 | `#D8D5C6` | 行分隔、栏分隔 |

> 强调色规则：三屏都用同一个位置（状态竖条），只换状态文案；**没有第二处橙色**（顶栏状态点在早期草稿里曾是橙色，已改墨色）。

## 三个状态的差异

| 状态 | 状态文案 | 分段条 | 明细第 1 行 | 字幕示例 |
|---|---|---|---|---|
| idle | 空闲 | 03/12 | 唤醒词 · 你好小智 | 你好，我在。 |
| listening | 在听 | 06/12 | 识别 · 实时转写 | 我在，请说。 |
| speaking | 在说 | 09/12 | 播报 · 剩余 2 句 | 客厅现在 23 度，湿度 48%。 |

其余元素（房间名、时间、WiFi、机器人、音量/网络明细）三屏完全一致，保证"同一块屏只换状态"。

- 参考（任务卡标注为 MIT；本机无浏览器、未在线复核许可文件，**只借鉴布局模式，不整段搬代码**）：

- 信息层级：房间名（32）> 状态（20 + 橙条）> 明细（14）；顶栏/字幕条为辅助。

## 重跑

```sh
python3 scripts/fonts/render_ui_v2.py   # 需 macOS 系统字体 Hiragino Sans GB / SF Mono
```

> 用同一份布局重渲染即可，字号与坐标不用改。

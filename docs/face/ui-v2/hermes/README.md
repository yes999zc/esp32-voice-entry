## 1. 素材来源与格式

- 目录：`<workspace>/04_Docs/human-bridge/assets/hermes-icon/`
- 使用：`hermes-face-64x72-a8.bin`（**4,608 B = 64×72×1 B**，raw A8 灰度 alpha，行优先，无头无 padding）
- 对照预览：`hermes-face-64x72-alpha.png`（64×72 RGBA，RGB 恒为 `#1F2B2D`，A 即同一份 mask）
- 已核对：`bin == png.alpha`（逐字节相等）；alpha 直方图 `[0,1)=1558 px`、`>224 = 2145 px`，四角 alpha=0（透明底）
- 另有两种官方导出（**本卡只用于对比，不缩放**）：
  - `hermes-face-56x64-a8.bin`（3,584 B）——降级方案用
  - `hermes-face-72x80-a8.bin`（5,760 B）——本卡未用
- **不做任何转图/拉伸**：全部按官方尺寸 1:1 合成；`56×64` 也直接读官方 bin，不是把 64×72 缩下去。

## 2. 渲染规则

| 项 | 规则 |
|---|---|
| 颜色 | RGB 恒定 `#1F2B2D`，alpha 取 A8 原值；不描边、不加方框/圆角、不投影 |
| 背景 | 直接 alpha 合成到纸白 `#F4F3EA`，**不烘焙白底** |
| 缩放 | 无（1:1）；需要 56×64 时用官方 bin |
| 断开态 | 整图 alpha × 0.4（`alpha*0.4` 后 round），**不闪、不呼吸、不做动画** |
| 其他 | 不用 `>_` 字符图标；不叠任何装饰 |

核对结果（渲染后反查）：在线/说话中两图在 `(408,168)-(472,240)` 区域与"官方 A8 + recolor"逐像素 **max diff = 0**；断开图为 **1/255**（×0.4 的取整误差，可接受）。

## 3. 坐标与避让

```

字幕条顶 262（底栏 60 = y260..320，字幕条 262..314）
头像底 → 字幕条顶留白 = 22 px
```

- 7 行日志全部保留，**最后一行不被头像覆盖**（日志止于 400，头像起于 408）；不需要减行、也不需要缩到 56×64。
- 左侧 64 px 状态条（状态/内存/帧）保持不变，与 task-17 的 A 版一致。

> ⚠️ **坐标口径差异（请 9哥 顺手确认）**：任务卡同时写了"底栏上方 8 px"和"y168..240"。

## 4. 三态

| 状态 | 顶栏 | 点 | 头像 | 左条状态 | 字幕示例 |
|---|---|---|---|---|---|
| 在线 | `Hermes 在线` | 橙色实心 8×8（**本屏唯一橙色**） | 不透明 | 在听 | 我在，请说。 |
| 断开/重连 | `Hermes 断开` | 空心墨色方点（2 px 描边、纸白填充） | **alpha×0.4** | 断开 | 链路断开，正在重连… |

- **文案只写"在线 / 断开"**，不写"已连接"：设备只知道与 309 的 WS 链路状态，不知道 Hermes 后端是否健康（避免过度承诺）。

- 橙色仅用于"链路在线"的点；断开态的点是空心墨色，不引入第二种强调色。

## 5. 顶栏宽度降级（从宽到窄）

| 级别 | 顶栏内容 | 触发 | 代价 |
|---|---|---|---|
| L0 | `● Hermes 在线` | 默认 | 无 |
| L1 | `● Hermes 在线` + 头像缩到 **56×64** | 右侧空间不足 | 官方 56×64 导出，日志右界可放到 408（+8 px） |
| L2 | `● Hermes`（去掉"在线/断开"，靠点形态区分） | 顶栏文字与右侧元素冲突 | 状态语义降级为点：实心橙=在线、空心=断开 |
| L3 | `●`（只留点） | 极窄/小屏 | 失去品牌文字，仅剩链路指示 |

- 降级顺序按 9哥 要求：**先缩头像（64→56），再退文案，最后只留点**。
- 本卡三张图都是 **L0**；L1 的占位差异见 `avatar-size-compare.png`。

## 6. 64×72 vs 56×64（官方导出，1:1）

| | 64×72（默认） | 56×64（降级） |
|---|---|---|
| 文件 | `hermes-face-64x72-a8.bin` | `hermes-face-56x64-a8.bin` |
| 字节 | 4,608 B | 3,584 B（−22.2%） |
| ink 覆盖率 | 65.5% | 66.6% |
| 占位 | 64×72，x408..472 / y168..240 | 56×64，x416..472 / y176..240 |
| 日志右界 | 400（沟 8 px） | 408（沟 8 px） |
| 观感 | 更完整、五官细节多 | 略小，缩图后仍可辨认 |

> 对比图里两个尺寸并排、均为官方原图，**没有做任何缩放**。

## 7. Phase B 实现提示（本卡不写代码）

- LVGL 9：A8 用 `lv_image_dsc_t` + `LV_COLOR_FORMAT_A8`；recolor 用 `lv_obj_set_style_image_recolor(obj, ink)` + `recolor_opa=255`，或预生成 RGB565A8。
- 断开态：`lv_obj_set_style_image_opa(obj, 102)`（0.4×255），不改素材、不做动画。
- 点位图：8×8 直接用 `lv_obj` 或 1-bit 小图；空心态用 2 px 边框。
- **不要运行时缩放**：56×64 走官方 bin，避免 LVGL 缩放的模糊与额外开销。
- 内存：A8 64×72 = 4.6 KB；56×64 = 3.5 KB；可忽略。
